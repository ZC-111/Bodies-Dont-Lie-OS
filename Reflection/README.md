# Reflection

## Purpose

Run the distillation cycle — reduce, simplify, and verify. Most knowledge systems grow; BDL OS shrinks toward clarity.

## What Belongs Here

- Daily reflection logs (`YYYY-MM-DD.md`)
- Consolidation decisions (merged files, removed duplicates)
- Truth audits ("Is this still true?")

## The Reflection Questions

Every cycle asks:

1. Can two documents become one?
2. Can this be expressed more simply?
3. Is this duplication?
4. Is this still true?
5. Can we remove it?
6. Does this belong in the Constitution, or only in a project?

## Naming Rules

- Daily: `YYYY-MM-DD.md`
- Audits: `audit-topic-name.md`

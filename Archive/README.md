# Archive

## Purpose

Preserve retired, superseded, or merged content without cluttering active folders.

## What Belongs Here

- Documents replaced by newer versions
- Merged files (with pointer to successor)
- Completed projects moved from Projects/

## Naming Rules

- Preserve original filename
- Add `ARCHIVED-YYYY-MM-DD` prefix or move to dated subfolder
- Always note why archived and what replaced it

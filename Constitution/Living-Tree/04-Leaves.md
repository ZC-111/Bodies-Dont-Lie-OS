# 04 — Leaves

| Field | Value |
|-------|-------|
| Layer | Leaves |
| Standard | [BDL-002](../BDL-002-Living-Tree.md) |
| Question | What is the smallest complete unit of knowledge? |

## Purpose

Leaves are atomic knowledge objects — each file answers exactly one question. The tree grows by adding leaves, not by enlarging existing ones.

## What Lives Here

- Files in [Knowledge/](../../Knowledge/README.md)
- One idea per file, one page maximum
- Linked to related leaves, never duplicated

## Examples

Instead of one "Immune System Guide," the tree holds:

- `What-Is-Inflammation.md`
- `How-Do-Cytokines-Work.md`
- `What-Raises-TNF-Alpha.md`

Each leaf links to its neighbors. Understanding emerges from composition.

## Test

Does this file contain more than one independent idea? If yes, split it into separate leaves.

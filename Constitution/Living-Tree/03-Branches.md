## Purpose

Branches group related knowledge by field or topic — immune, nutrition, ecology, engineering. They emerge when content exists, not before.

## What Lives Here

- Subfolders in [Knowledge/](../../Knowledge/README.md): `Knowledge/immune/`, `Knowledge/nutrition/`, etc.
- Domain-specific skills in [Skills/](../../Skills/README.md)
- Domain research in [Research/](../../Research/README.md)

## Rules

1. Create a branch only when you have at least one leaf to put on it.
2. Name branches by domain, not by document type.
3. A branch README answers the four standard questions.

## Test

Does this folder contain multiple related leaves? If it holds only one file, it may not need a branch yet.

## Purpose

Pruning is deliberate reduction — the counterweight to growth. Most knowledge systems accumulate; BDL OS distills.

## When to Prune

Every [Reflection/](../../Reflection/README.md) cycle asks:

1. Can two documents become one?
2. Can this be expressed more simply?
3. Is this duplication?
4. Is this still true?
5. Can we remove it?
6. Does this belong in the Constitution, or only in a project?

## Actions

| Finding | Action |
|---------|--------|
| Duplicate content | Merge into one leaf; link from the other |
| Outdated content | Move to [Archive/](../../Archive/README.md) |
| Overgrown document | Split into atomic leaves |
| Wrong layer | Move (e.g. domain content out of Constitution) |

## Test

Is the repository clearer than last cycle? If not, pruning is overdue.

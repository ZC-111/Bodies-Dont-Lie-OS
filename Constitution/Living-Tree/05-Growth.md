# 05 — Growth

| Field | Value |
|-------|-------|
| Layer | Growth |
| Standard | [BDL-002](../BDL-002-Living-Tree.md) |
| Question | How does the tree expand without becoming a book? |

## Purpose

Growth rules ensure the Living Tree expands through addition at the leaves, not inflation of existing documents.

## Rules

1. **Add leaves, not pages.** New knowledge = new file, not longer file.
2. **Earn branches.** Create a domain folder only when content justifies it.
3. **Link outward.** Connect new leaves to existing ones; build the graph.
4. **Projects feed the tree.** Completed [Projects/](../../Projects/README.md) produce leaves in Knowledge.
5. **Standards grow slowly.** New BDL numbers (003, 004…) require demonstrated, cross-domain need.

## Test

Did this change add a leaf, or did it enlarge an existing document? Enlargement requires justification.

## Purpose

The Wayfinding Kernel is the operational core of Bodies Don't Lie OS. It defines the cycle every project follows — from first observation to validated learning.

Where [BDL-000](BDL-000-Constitution.md) states *what* we believe, BDL-001 defines *how* we work.

---

## The Cycle

Every project follows the same eight stages. No stage may be skipped intentionally.

```
Observe → Measure → Understand → Model → Predict → Build → Validate → Learn ↺
```

Each stage is an atomic document in [Wayfinding/](Wayfinding/).

| Stage | Question | Document |
|-------|----------|----------|
| 1 | What is the system showing us? | [01-Observe.md](Wayfinding/01-Observe.md) |
| 2 | What can we quantify or structure? | [02-Measure.md](Wayfinding/02-Measure.md) |
| 3 | Why is this happening? | [03-Understand.md](Wayfinding/03-Understand.md) |
| 4 | How do we represent this system? | [04-Model.md](Wayfinding/04-Model.md) |
| 5 | What should happen next? | [05-Predict.md](Wayfinding/05-Predict.md) |
| 6 | What do we create or change? | [06-Build.md](Wayfinding/06-Build.md) |
| 7 | Did reality match expectation? | [07-Validate.md](Wayfinding/07-Validate.md) |
| 8 | What did we learn? | [08-Learn.md](Wayfinding/08-Learn.md) |

---

## Rules

1. **Order matters.** Each stage builds on the previous. Jumping ahead creates false confidence.
2. **No intentional skips.** You may revisit a stage, but you may not pretend earlier stages are done.
3. **Evidence at every stage.** Each stage produces an artifact — a note, measurement, model, or result.
4. **Learn loops back to Observe.** The cycle never ends; understanding deepens with each pass.

## Non-Goals

The Wayfinding Kernel does **not**:

- Prescribe specific tools, metrics, or methodologies
- Replace domain expertise or professional judgment
- Guarantee correct answers — it guarantees a disciplined process

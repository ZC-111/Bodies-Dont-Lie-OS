# 013 — Atomic Knowledge

| Field | Value |
|-------|-------|
| Type | Design Principle |
| Article | IV |

## Principle

Every document should represent a single complete idea. Knowledge grows by linking modules, not by enlarging documents.

## Meaning

If a document contains multiple independent ideas, divide it. One page. One principle. One responsibility. Compose understanding through links, not through length.

## Test

Does this file contain more than one independent idea? If yes, split it.

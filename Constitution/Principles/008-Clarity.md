# 008 — Clarity

| Field | Value |
|-------|-------|
| Type | Design Principle |
| Article | IV |

## Principle

Every document, workflow, and component should be understandable in one read.

## Meaning

Clarity is not dumbing down — it is respecting the reader's time. If something requires re-reading to understand, it needs revision.

## Test

Can someone understand this in one read without prior context?

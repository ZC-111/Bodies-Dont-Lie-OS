# 009 — Simplicity

| Field | Value |
|-------|-------|
| Type | Design Principle |
| Article | IV |

## Principle

Complexity is a liability. Reduce until removing anything else would reduce understanding or capability.

## Meaning

**Less, but complete.** Every word, folder, and workflow is maintenance debt. Simplify before optimizing. Remove before adding.

## Test

Can anything be removed without loss? If yes, remove it.

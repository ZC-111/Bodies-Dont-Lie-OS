# 010 — Modularity

| Field | Value |
|-------|-------|
| Type | Design Principle |
| Article | IV |

## Principle

Everything should do one thing well and snap together with other modules.

## Meaning

High cohesion, low coupling. The LEGO Rule:

```
Principle + Skill + Research + Workflow = Feature
```

No duplication. No giant files. Just reusable building blocks.

## Test

Does this module have exactly one responsibility? Can it be composed without copying?

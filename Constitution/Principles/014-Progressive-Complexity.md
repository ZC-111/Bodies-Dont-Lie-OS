# 014 — Progressive Complexity

| Field | Value |
|-------|-------|
| Type | Design Principle |
| Article | IV |

## Principle

Begin with the simplest thing that works. Complexity must be earned through demonstrated need.

## Meaning

When structure and relationships are well organized, function can emerge naturally. Look for the most fundamental pattern before adding interventions — in knowledge, workflows, and code.

Remove before adding. Simplify before optimizing. Prefer composition over expansion.

## Test

Is this the simplest thing that works? What demonstrated need justifies added complexity?

# 02 — Measure

| Field | Value |
|-------|-------|
| Stage | 2 of 8 |
| Standard | [BDL-001](../BDL-001-Wayfinding-Kernel.md) |
| Question | What can we quantify or structure? |

## Purpose

Make observations explicit, repeatable, and comparable. Measurement turns noticing into evidence.

## Inputs

- Observation log from [01-Observe.md](01-Observe.md)
- Decision about what to measure and how

## Outputs

- Structured data: numbers, categories, timestamps, or scales
- Measurement method documented (so others can repeat it)
- Baseline or reference point, if applicable

## Test

Could someone else repeat this measurement and get a comparable result? If not, document why.

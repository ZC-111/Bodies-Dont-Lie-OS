# 04 — Model

| Field | Value |
|-------|-------|
| Stage | 4 of 8 |
| Standard | [BDL-001](../BDL-001-Wayfinding-Kernel.md) |
| Question | How do we represent this system? |

## Purpose

Create a simplified representation that captures essential relationships. A model is a map — useful, imperfect, testable.

## Inputs

- Understanding from [03-Understand.md](03-Understand.md)
- Decision about scope: what the model includes and excludes

## Outputs

- Model description: components, relationships, boundaries
- Explicit simplifications and assumptions
- Link to supporting evidence

## Test

Does the model make falsifiable claims? A model that explains everything explains nothing.

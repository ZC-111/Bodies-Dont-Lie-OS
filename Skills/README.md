# Skills

## Purpose

Define reusable capabilities — procedures, workflows, and methods that snap together with principles and knowledge.

## What Belongs Here

- Step-by-step procedures
- Agent skills and automation patterns
- Workflow definitions

## Naming Rules

- `Skill-Name.md` or `domain/Skill-Name.md`
- One skill, one responsibility
- Reference knowledge objects; don't embed them

- [Knowledge](../Knowledge/README.md) — Domain facts skills depend on

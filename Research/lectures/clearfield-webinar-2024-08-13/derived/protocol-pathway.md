## 1. Indication & Scope

**For:** Complex chronic illness where siloed specialty care fails (post-infectious, autoimmune polarity, toxin/EMF burden, metabolic + hormone imbalance, cancer-as-abnormal-regeneration framing).

**Not for / refer out:** Unstable acute disease, emergency neurology/cardiology, active suicidal crisis, or any setting lacking monitoring for proposed immunomodulators / hormones / detox agents.

**Lecture framing:** Shared CDPM language — pick the **lead pillar for this patient**, then sweep the others; use objective vascular/ANS scores as the clinic “stethoscope.”

## 2. Entry Criteria

### History / clinical picture
- Multi-system chronic disease; toxin/occupational exposures; autoimmunity; post-spike/EMF brain fog; metabolic syndrome / hormone imbalance; cancer adjunct context
- Avoid day-one polytherapy — history + exam decide which toxin labs to run

### Labs / imaging (as stated)
- **Redox:** GSH redox / NAD (when available); urinary 8-oxo-guanosine; endothelial PPG after brachial occlusion; ANS + sudomotor
- **Immune:** lymphocyte / cytokine map (Th1/Th2/Th17); CBC differential clues (neutrophilia↔Th17; lymphocytosis↔Th1; basophils↔Th2)
- **Metabolic:** sex steroids with **E1/E2/E3 ratios**; HOMA-IR; iodine/selenium context; nutrigenomic SNPs as available
- **Homocysteine:** treat with full quartet, not B12 alone
- Optional: metals / mycotoxins / spike labs **only if history warrants**

### Red flags → escalate / do not start pathway
- Blanket steroid suppression without polarization map (cancer/infection risk framing)
- “Detox everyone” without targeting
- Thymosin β-4/β-2 in active cancer contexts (speaker: avoid; prefer Th1 agents e.g. thymosin α-1)

## 3. Pathway Overview

```text
[History + endothelial/ANS baseline]
        ↓
 Choose LEAD pillar by dominant presentation
        ↓
 Sweep remaining pillars (overlap allowed — e.g. IN progesterone = metabolic + immune)
        ↓
 Monitor scores weeks–months (ozone, HRT, detox, peptides, etc.)
        ↓
 Regenerative / cancer layers LAST after metabolic + immune + redox addressed
```

| Phase | Goal | Typical duration (as stated) |
|---|---|---|
| 0 Baseline | Endothelial / ANS / sudomotor scores | Day 0 |
| Lead pillar | Fix primary driver | Individualized |
| Sweep | Address other three pillars without candy-shop stacking | Overlapping |
| Monitor | Re-score interventions objectively | Weeks–months |
| Regenerative | Healing / anti-fibrotic / abnormal-regen (cancer) layers | After prior pillars |

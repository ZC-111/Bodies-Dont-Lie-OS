## 🔄 Infographic 5: "The Four R Ladder"

**Title:** Clearfield Gut Reset Sequence

```
1 REMOVE  → white flour, sugar, dairy, gluten, corn (+ other triggers)
2 REPAIR  → whole foods; DGL (upper GI); L-glutamine (lower GI)
3 RESTORE → prebiotics + probiotics + postbiotics / fermented foods
4 REPLACE → digestive enzymes + Himalayan/sea salt (gastrin/HCl support)
```

**Adjuncts:** zinc (junctions), vitamin A, condition-specific antimicrobials when indicated

## 🧠 Infographic 7: "Gut–Hormone–Brain Links"

**Title:** Why Cortisol & Neurosteroids Belong on the Gut Chart

```
Cortisol excess  →  ↓ beneficial flora  →  dysbiosis + low-grade inflammation
Fiber / inulin   →  ↓ cortisol signal + cognition support
DHEA            →  balance high cortisol (track ratio)

PREGNENOLONE PATH (brain)
  → progesterone → allopregnanolone → GABA (calm)
  Benzos hitchhike this path — integrative care aims upstream

AUTISM / TBI framing
  IL-6 excess → relative IGF-1 deficiency → executive dysfunction
```

**Footer:** Barrier + bugs + hormones — treat the triangle, not one corner.

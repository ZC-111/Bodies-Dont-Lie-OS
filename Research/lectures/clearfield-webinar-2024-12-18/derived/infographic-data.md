## 🎯 Infographic 1: "When to Track Beyond Fertility"

**Title:** Urinary Hormone Tracking — Clinical Use Map

| Setting | What you're looking for |
|---|---|
| PCOS / PMS / PMDD / endometriosis | Coordinated vs chaotic hormone pattern |
| Coming off birth control | Return of coordinated E–LH–P–FSH |
| Postpartum / post-miscarriage | Reboot of ovulatory pattern |
| Ablation / ovaries retained post-hysterectomy | Fluctuations without a period landmark |
| Perimenopause | Stage transition; time cooperative P |
| Athletes / under-fueling | Suppressed E, amenorrhea recovery |
| TTC / infertility | Full pattern vs LH-only OPK |

**Footer:** Every woman with fluctuating ovarian hormones — not only those trying to conceive.

## 📈 Infographic 2: "The Coordinated Cycle Checklist"

**Title:** Three Questions for Every Chart

```
1. COORDINATED?
   E3G rises → LH (± FSH) surge → PDG rises
   Bleed alone ≠ ovulation

2. IN RANGE?
   Most points fit the reference curve
   (urine units ≠ serum units)

3. CYCLE STABLE?
   Length ~25–35 days
   Cycle-to-cycle variation ≤ 3 days
```

**Callout:** Uncoordinated hormones can hide under "regular periods."

## 🧬 Infographic 3: "Metabolite → Hormone Decoder"

**Title:** What the Wand Is Actually Measuring

| Urinary marker | Reflects | Clinical job |
|---|---|---|
| **E3G** | Estradiol (E2) breakdown | Follicular + luteal estrogen hills |
| **LH** | LH surge | Ovulation trigger (1–3 days ideal) |
| **PDG** | Progesterone | Confirm ovulation; luteal adequacy |
| **FSH** | FSH (separate wand on Mira) | Surge with LH; DOR / perimenopause |

**Footer:** Slight delay vs serum — pattern still correlates (2015 + small n=4 AUC studies; larger n≈50 pending).

## ⚠️ Infographic 4: "LH Red Flags"

**Title:** Not All Surges Are Created Equal

```
NORMAL
  Low baseline → spike/plateau 1–3 days → back down

PROBLEM A — High baseline LH
  Chronically elevated → ovary desensitized
  (common PCOS pattern)

PROBLEM B — Marathon surge
  5–8 day "surge" → ovulated somewhere in there
  but not optimized

PROBLEM C — Non-ovulatory surge
  LH fires → no PDG rise → body tries again
  (don't time labs off the failed surge)
```

## 🔄 Infographic 5: "Estrogen Pattern Triage"

**Title:** Large Hill, Small Hill — or Trouble

| Pattern | Meaning | Think about |
|---|---|---|
| Rise → decline → smaller luteal rise | Ideal | Maintain |
| Flat / no follicular rise | Poor follicular development | Under-eating, low fat, over-exercise |
| No luteal E rise | Weak/failed ovulation or LUF | Egg quality / rupture |
| Reverse (low follicular / high luteal) | Hormone mismatch | PMS, heavy menses, prolactin workup |

**Callout:** One mid-luteal blood test can miss reverse-pattern severity.

## 💊 Infographic 6: "Cooperative HRT Timing"

**Title:** Stop Guessing Cycle Day 15

```
PERIMENOPAUSE — still surging?
        │
        ▼
  Detect LH surge on chart
        │
        ▼
  Start bioidentical P ~3 days later
  ("cooperative HRT")
        │
        ▼
  Support natural luteal process

Lost coordination / anovulatory?
  → Daily or fixed cyclical P may fit better
```

**Routes & urine visibility:**
- Oral / vaginal / injectable P → PDG often **ceilings**
- Transdermal P/E → slight change; **underlying pattern still visible**

## 💰 Infographic 7: "Cost Reality Check — Mira vs Cycle Mapping"

**Title:** Three Months of Data for the Price of One Map

| Approach | What you get | Rough cost framing |
|---|---|---|
| DUTCH / mail-in cycle map | Fixed sample days; delayed results | One cycle ≈ baseline |
| **Mira (immunofluorescence)** | Real-time; flexible cadence | **~$330** analyzer + 3 boxes ≈ 3 months near-daily |
| LH-only OPK strips | Surge only | Cheap but incomplete |
| Daily serum draws | Gold-standard snapshots | Cost + clinic friction |

**Cost cutters:** Test every other day; denser luteal-only; pause when optimized.

**Does not replace:** T/androgens, cortisol pathways, full OH-estrogen metabolite panels.

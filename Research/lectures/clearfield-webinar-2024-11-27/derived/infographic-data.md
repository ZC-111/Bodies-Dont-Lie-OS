## 👩 Infographic 3: "Why Women Carry ~2× Dementia Risk"

**Title:** Not Because They Live Longer

1. **Pregnancy** — MRI brain shrinkage; changes may persist ≥6 years  
2. **Lifetime estrogen exposure** — menarche, pregnancies, OCPs, menopause age, HRT  
3. **Estrogen loss** — impaired mito glucose use; white-matter burned for ketones (worse if **APOE4**)  
4. **Hot flashes** — gray-matter microintensities ↑ cognitive risk  
5. **Menopause atrophy** — frontal/temporal cortex + hippocampus shrink  

**Footer:** Estrogen = anabolic / BDNF / spines / cholinergic. Progesterone = myelin repair + anti-inflammatory neuroprotection.

## 📏 Infographic 4: "Measure It → Mend It → Maximize It"

**Title:** Clinic Testing Stack for Cognitive Risk

| Tier | Tools |
|---|---|
| Genetics | APOE (E2 protect / E3 neutral / E4 risk) |
| Brain function | P300 EEG, Trail Making Test |
| Metabolic | HOMA (fasting insulin+glucose), HbA1c, waist-hip, lipids |
| Neurotox / inflam | Homocysteine (tight targets), CRP/ESR, vitamin D, NO saliva |
| Environmental | Visual contrast sensitivity (mold + amyloid/tau signal) |
| Optional | Omega-3 index 8–12% (often skip if supplementing) |

**Callout:** Homocysteine example targets: **≤5 @40**, **≤6 @50** — lower than many lab cutoffs.

## 🏃 Infographic 5: "BDNF & Brain Reserve Ladder"

**Title:** Movement Is the Closest Thing to a Magic Pill

```
LEVEL 1  4,000 steps/day          → ↑ gray matter (reserve)
LEVEL 2  Boxing / dancing         → complex motor + cognitive load
LEVEL 3  HIIT 2–3×/week           → heat + lactate → BDNF surge
LEVEL 4  Strength + grip work     → aging/frailty signal
ADJUNCT  Sauna / heat therapy      → BDNF ↑, cortisol ↓
```

**Also raises reserve:** omega-3s, midlife HRT (when appropriate), toxin/stress reduction  
**Cognitive reserve #1 in adults:** social engagement (education/work learning prevent earlier)

## 😴 Infographic 6: "Sleep Without the Dogma"

**Title:** Insomnia Can Be a Dementia Prodrome

| Approach | Signal from lecture |
|---|---|
| Behavioral hygiene | Best evidence base (light, caffeine, alcohol, nocturia, exercise) |
| Melatonin | ~**20–30 min** more sleep; may support neurons |
| Trazodone-class | ~42 min cited; balance daytime sedation |
| Hypnotic benzos | Avoid in elderly — falls + cognitive harm |
| Daytime stimulants | Generally not for dementia fatigue |
| Glymphatic “detox” story | **2024 study:** sleep may ↓ clearance vs prior hypothesis — stay flexible |

**Target sleep window cited:** **>7h and <8.5h**

## 🦠 Infographic 7: "PANDAS → PANS: Overnight Is the Clue"

**Title:** Mental Illness Doesn’t Usually Appear Overnight

```
Classic PANDAS          Modern PANS
──────────────          ───────────
Post-strep       →      Strep + mycoplasma, EBV,
Debilitating OCD        Coxsackie, HHV-6, others
Abx × ~1 month   →      Targeted anti-infectives
Symptoms resolve        when titers + symptoms move
```

**Red flag:** Previously well child/adult → sudden OCD, psychosis, severe insomnia, emotional dysregulation  
**Pearl:** Gaslighting is common; high index of suspicion saves lives/function

## 💊 Infographic 8: "HRT Timing & Omega-3 Practical Dosing"

**Title:** Two High-Yield Clinical Levers

**HRT timing**
| Window | Action |
|---|---|
| Just before menopause | Preferred start (bone ±1.5y window) |
| Within ~10 years | Strongest systemic benefit narrative |
| Past window / 60–70+ | Individualize; **start low/slow**; monitor brain + metabolism |
| Urogenital aging any age | Intravaginal estrogen/DHEA — UTI/sepsis prevention angle |

**Omega-3 titration (Smurz)**
```
Start:   ~2 g/day
Common:  ~3 g/day
Upper:   up to ~5 g if GI OK (greasy stool = back off)
Test:    often skip ($150) vs just supplement (~$40)
```

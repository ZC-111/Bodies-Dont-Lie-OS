## 🦴 Infographic 4: "Vitamin K2 — The Calcium Traffic Cop"

**Title:** D Without K2 Is Incomplete

```
Vitamin D + Calcium alone
  → Don’t know where to go
  → Deposit in INTIMAL vessel layers
  → Atherogenic plaque risk ↑

Vitamin K2 (MK-4 / MK-7)
  → Activates osteocalcin + matrix Gla protein
  → Directs Ca to MEDIAL layers
  → Vessel flexibility ↑ / bone support
```

**Ratio rule:** Vitamin D : K2 = **10 : 1** (5,000 IU D → 500 mcg K2)  
**Safety:** K2 ≠ K1 clotting story; K3 is toxic — don’t use.

## 🎯 Infographic 1: "LDL Is Not Just a Villain"

**Title:** What LDL Cholesterol Actually Does

```
LDL PACKAGE (from liver)
  │
  ├── Steroid hormones (pregnenolone → prog / DHEA / T / E)
  ├── Vitamin D precursor (skin 7-dehydrocholesterol + UV)
  ├── Cell membrane fluidity & stability
  ├── Bile acids / fat-soluble vitamin absorption
  ├── Brain & myelin support
  └── Immune / repair signaling
```

**Footer:** Suppress LDL blindly → risk hormone loss, fog, CoQ10 deficit, worse diabetes control.

## 🕳️ Infographic 4: "Homocysteine + Ox-LDL = Plaque"

**Title:** The Two-Hit Arterial Story

```
1. ROS / fried oils → oxidized LDL (esp. small dense)
2. Homocysteine damages arterial wall ("holes")
3. Ox-LDL lodges → inflammation
4. Monocytes → macrophages → foam cells → death pile = PLAQUE
```

**Action:** Always measure **homocysteine** with advanced lipids — basic panels miss it.

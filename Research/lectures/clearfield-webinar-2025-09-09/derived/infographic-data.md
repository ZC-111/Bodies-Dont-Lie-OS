## 🎯 Infographic 1: "Detect → Remove → Repair"

**Title:** Campbell's Three Rules for Toxin Illness

```
1. DETECT the cause   →  right diagnosis (serum IgG/IgE mycotoxins, not urine)
2. REMOVE the cause   →  leave / remediate exposure + kill spore source
3. REPAIR the damage  →  targeted antifungals + specific nutrients + diet
```

**Footer:** Wrong diagnosis or wrong treatment = patients stay sick for months to years.

## 📏 Infographic 2: "Size Matters — What You're Breathing"

| Particle | Size | Clinical meaning |
|---|---|---|
| Human hair | ~100 µm | Visible scale |
| Mold spores | ~3–4 µm | Reach alveoli → blood → brain |
| Mycotoxins | ~0.1 µm | Molecular toxins; COVID-size scale |

**Callouts:**
- Exposure: **inhalation + dermal** (ingestion minimal for indoor illness)
- One mold → **many** mycotoxins
- Hard to filter at spore size

## 🧪 Infographic 3: "Test Right — Blood vs Urine"

**Title:** Why Serum Beats Urine for Mycotoxins

| Method | Campbell verdict |
|---|---|
| Urine mycotoxins | ❌ Not CDC/FDA recognized; unvalidated; exposure ≠ disease |
| OATs “fungal markers” | ❌ Often don't measure what they claim |
| ERMI | ❌ EPA experimental (2013) — do not use clinically |
| Petri dish home kits | ❌ Not definitive for illness |
| **Serum IgG + IgE × 14 toxins** | ✅ Preferred (28 results); retest ≥6 months |

**Footer:** T-2 urine accuracy cited ~20% (≈80% inaccurate) in April study discussed.

## 💊 Infographic 4: "Mycotoxin Treatment Stack"

**Title:** Six-Month Protocol Building Blocks

```
EXPOSURE OFF
  │  Remediatiate HVAC / basement / bathrooms OR relocate
  │
ANTIFUNGAL
  │  Itraconazole 100 mg BID with food
  │  (~10% → brand Sporanox if generic fails)
  │  ± Amphotericin B nasal spray for fungal sinusitis
  │
NUTRIENTS
  │  8 specific vitamins/supplements (Detox Pure kit)
  │  Spore-forming bacilli (not acid-killed Lactobacillus hype)
  │  Melatonin 3 mg (brain toxin clearance signal)
  │
DIET
     Low-histamine, anti-inflammatory nutrition
```

**Callout:** Textbook antifungal duration 12–18 months; Campbell: ~**6 months** with full stack + exposure control.

## 🧠 Infographic 5: "Brain First — Neurological Red Flags"

**Title:** Mycotoxins Hit the Brain Before the Brochure Diagnosis

**Often mislabeled as:**
- Fibromyalgia / CFS
- Chronic Lyme
- Treatment-resistant depression/anxiety
- Autoimmune / demyelinating disease
- POTS / dysautonomia

**Associations discussed:**
ASD, memory loss, CIDP, optic neuritis, MS (gliotoxin), Parkinson (ochratoxin), ALS, Alzheimer fungal findings, brain fog

**Footer:** Brain = 2% body weight, 20% oxygen, first stop for inhaled mycotoxins.

## 🚫 Infographic 6: "What Doesn't Work (Per Campbell)"

**Title:** Drop These Before You Call It Detox Failure

| Intervention | Why it fails here |
|---|---|
| Binders (charcoal, zeolite, clays) | No human efficacy data; bind minerals; aflatoxin-centric |
| Glutathione / NAC (gliotoxin cases) | ↑ Gliotoxin cytotoxicity |
| Fluconazole alone | Yeast only — not multicellular molds |
| HBOT as cure | Helps little; doesn't clear mycotoxins |
| Ozone / plasmapheresis | No supporting mycotoxin evidence |
| Clorox wipe-downs | ~92% water; drives mold deeper |
| Years of IV antibiotics for “chronic Lyme” | 5 trials: no sustained PTLDS benefit |

## 👃 Infographic 7: "Chronic Sinusitis → Brain Pathway"


## ⚠️ Infographic 8: "Vitamin C — Check Ferritin First"

**Title:** Hero Nutrient, Villain with Iron Overload

```
LOW / NORMAL IRON          HIGH FERRITIN
Vitamin C helps:           Vitamin C risks:
 • Immunity                • Fe³⁺ → Fe²⁺ (Fenton)
 • Antihistamine effect    • Oxidative stress
 • Collagen / healing      • Liver / heart / endocrine injury

DOSE LADDER (high ferritin):
  under 100 mg/day → relatively safer
  200–1000 mg/day  → increasing risk
  2000+ mg/day     → dangerous without labs
```

**Action:** Full iron panel + transferrin saturation before megadose oral or IV vitamin C.

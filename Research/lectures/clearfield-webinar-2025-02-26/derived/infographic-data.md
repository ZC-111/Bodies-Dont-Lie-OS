## 🎯 Infographic 1: "Myths vs Reality — Cannabis Medicine"

**Title:** Stop Repeating Dispensary Folklore

| Myth | Reality |
|---|---|
| CBD isn’t psychoactive | Acts in brain (anxiety) — psychoactive, **not intoxicating** |
| More THC = better medicine | **Balanced ratios** often outperform mega-THC |
| CBD has no side effects | Sedation, dry mouth, diarrhea, **drug interactions** |
| Can’t overdose | Unlikely fatal, but anxiety/paranoia/CHS are real |
| Indica vs sativa decides effect | **Terpenes + chemovar COA** decide effect |
| All CBD products are equal | Full spectrum / broad spectrum / isolate differ radically |

**Footer:** Quinn’s bar: safety, efficacy, affordability — then educate the patient.

## 🧬 Infographic 2: "The ECS Triad"

**Title:** Endocannabinoid System in One Glance

```
ECS = SIGNALING SYSTEM (every organ system)
  │
  ├── RECEPTORS: CB1, CB2, CB3/GPR55-class, TRP channels…
  │
  ├── LIGANDS: Anandamide (AEA / “bliss”), 2-AG, PEA
  │
  └── ENZYMES: make & break (FAAH breaks down endocannabinoids)
```

**Callout:** Stress ↑ FAAH → faster breakdown → weaker endocannabinoid tone.

**Footer:** ~58% of brain transmembrane receptors framed as cannabinoid-related in this lecture.

## ⚖️ Infographic 3: "Full / Broad / Isolate"

**Title:** Know Your Spectrum Before You Recommend

| Type | Contains | Clinical note |
|---|---|---|
| **Full spectrum** | Cannabinoids + terpenes + flavonoids **including THC** | Closest to entourage matrix |
| **Broad spectrum** | Same matrix **minus THC** | Useful when THC must stay near zero |
| **Isolate** | Single molecule (e.g., CBD or THC) | Epidiolex / Marinol lessons: more dose, less synergy |

**Rule:** “I’ve been taking CBD” is not a drug history — ask which spectrum and demand a COA.

## 🌿 Infographic 4: "Entourage vs Orchestral"

**Title:** Two Synergy Frameworks

```
ENTOURAGE EFFECT
  Plant constituents together
  (cannabinoids + terpenes + flavonoids)
  → better than isolates

ORCHESTRAL EFFECT
  Plant matrix + added agents
  (theanine, melatonin, curcumin, PEA, MSM, BioPerine…)
  → target sleep / anxiety / pain / inflammation
```

**Footer:** Russo “Taming THC” (2011) = foundational reading for entourage literacy.

## 💊 Infographic 5: "THC vs CBD — Clinical Split"

**Title:** Same Plant Family, Different Jobs

| Dimension | THC | CBD |
|---|---|---|
| Receptor action | Partial agonist CB1/CB2 | Negative allosteric modulator CB1 |
| Intoxication | Yes | No |
| Anxiety | High doses often worsen | Often first-line plant tool |
| Cancer cells | Can **kill** | Inhibits growth / metastasis |
| Under 25 | Avoid | Prefer non-THC strategies |

**Callout:** Ethan Russo framing cited: CBD effects are enhanced by some THC.

## 🧪 Infographic 6: "COA Checklist Before You Endorse"

**Title:** Certificate of Analysis — Non-Negotiables

1. Third-party lab (not in-house marketing PDF)
2. Heavy metals — watch **sum**, not only each metal under limit
3. Pesticides / herbicides / fungicides (labs don’t all test the same list)
4. Microbes / mycotoxins
5. Cannabinoid panel + **total THC** (Δ8 + Δ9 + acids + analogs)
6. Terpene panel
7. Residual solvents matching extraction method
8. Product photo / finished-goods testing when available

**Red flags:** No terpenes on a “full spectrum” label; only Δ9 listed; garage extraction; butane lore.

## 🩹 Infographic 7: "Pain Stack Anchors"

**Title:** Beyond “Take Some CBD”

```
CORE: Full-spectrum cannabinoids (homeostasis / CB1 pain gating)
  │
  ├── PEA 300–1200 mg/day (ECS-like; mast cells; GPR55/119)
  ├── Curcumin + BioPerine (anti-inflammatory + absorption)
  ├── MSM (sulfur / connective tissue; avoid true sulfur allergy)
  └── Phenylalanine (pain + mood amino pathway)
```

**Opioid angle:** CBD may hyperpolarize pain pathways with less Ca2+-driven oxidative stress than opioids → potential weaning adjunct (panel discussion).

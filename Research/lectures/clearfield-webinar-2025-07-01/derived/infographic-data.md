## 🧄 Infographic 1: "Garlic vs Pharmaceutical Lead Chelation"

**Title:** Food-Based Chelator With Drug-Level Data

| Arm | Dose | Blood lead change (4 weeks) | Tolerability |
|---|---|---|---|
| **Garlic tablets** | 3.6 g/day | **~20 → ~12 µg/dL** | Fewer AEs; symptom improvement |
| D-penicillamine | Pharma chelator | Similar reduction | More nausea / skin reactions |
| Placebo | — | Minimal | — |

**Callout:** Sulfur thiols (allicin, SAC, diallyl disulfide) bind Pb / Hg / Cd **without stripping Zn & Ca** the way EDTA often does.

**Footer:** Practical dose = standardized tablets or aged garlic extract **1.2–3.6 g/day** (not 6–10 raw cloves).

## ⚖️ Infographic 4: "AA vs SA — Choose the Form"

**Title:** Same Ion, Different Pharmacology

| | Ascorbic acid | Sodium ascorbate |
|---|---|---|
| pH | 2.2–2.4 (buffered ~5.2–5.4) | **7.4–7.8** |
| Transport | Passive GLUT | **Active SVCT1/2** |
| IV veins | Phlebitis / sclerosis risk | Better tolerated |
| Mouth/teeth | Enamel damage | Preferred (dental protocols) |
| Oncology TME | May acidify further | pH-neutral fit |
| Orthomolecular lineage | Often misused modern default | **Klenner / Cathcart standard** |

**Callout:** Avoid calcium ascorbate for high-dose titration — overdose mineral, underdose C.

## 🛡️ Infographic 5: "IVC Safety Gate Checklist"

**Title:** Before High-Dose Intravenous Ascorbate

```
1. G6PD          → Absolute screen if > ~25 g (oncology 50–300 g/24h cited)
2. Renal function → Hydrate + monitor; oxalate risk if clearance impaired
3. Iron status    → Caution in hemochromatosis / overload
4. Fluid status   → CHF, malignant ascites, advanced CKD → monitor closely
```

**Footer:** Safety is protocol + screening — not the molecule alone.

## 🥤 Infographic 6: "SIP 7-to-7 Protocol"

**Title:** Stable Levels From Wake to Wind-Down

**Maintenance**
```
1 tsp ≈ 4 g sodium ascorbate
→ Dilute in filtered water
→ Sip every 20–30 min (7→7)
→ Separate hydration bottle required
```

**Acute infection / post-op**
```
Load 1 tsp
→ Redose q2–4h to gut tolerance (“C flush”)
→ Titrate down
→ Continue ≥72h after symptoms resolve
```

**Rule:** Medical-grade pure SA only — no AA, no effervescent junk.

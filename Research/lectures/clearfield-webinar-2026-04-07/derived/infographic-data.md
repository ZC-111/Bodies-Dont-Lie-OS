## Infographic 1: "The Four Sisters of Estrogen"

**Title:** Know Which Sister You’re Prescribing

| Sister | Code | One-line cue |
|---|---|---|
| Estrone | **E1** | Postmenopausal workhorse; reservoir via adipose/adrenal |
| Estradiol | **E2** | The “brain & body” modulator — secondary sex characteristics |
| Estriol | **E3** | Downstream only — **cannot** climb back to E1/E2 |
| Estetrol | **E4** | Fetal/pregnancy estrogen — OC pairing (FDA 2021) |

**Footer (Serna teaching):** Draw E1 ↔ E2; draw a one-way arrow down to E3. Patients remember personalities better than structures.

## Infographic 2: "ERα vs ERβ — Why Balance Matters"

**Title:** Same Hormone Family, Different Jobs

```
ERα (proliferative hotspots)     ERβ (modulatory hotspots)
─────────────────────────────    ────────────────────────────
Mammary / uterus                 Prostate epithelium / bladder
Ovary theca / bone               Granulosa / colon
Liver / adipose / prostate       Adipose / immune / CNS lean
stroma                           Less clotting signal than α
↑ proliferation if unbalanced
```

**Callout:** Overdrive ERα without β/context → cancer & clotting narratives Serna emphasized.

## Infographic 3: "PT-141 — Brain First, Plumbing Second"

**Title:** Why PDE5 Alone Sometimes Fails

```
PDE5 inhibitors                    PT-141 (bremelanotide)
────────────────                   ──────────────────────
Peripheral NO / vessels            Central MC4 / hypothalamus
“Can I get blood flow?”            “Do I want / initiate?”
Fails if motivation is the issue   ↑ dopamine / reward / arousal
```

**Combo caution:** Historic priapism warning with PDE5i — emerging salvage trials for non-responders.

**FDA label cue:** Vyleesi = premenopausal HSDD (not postmenopausal label).

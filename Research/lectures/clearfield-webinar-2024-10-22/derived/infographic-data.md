## 🧬 Infographic 2: "Inflammation → Leaky Brain → Depression"

**Title:** Same Cascade, Different Organs

```
VISCERAL FAT (endocrine organ)
  → Cytokines / low-grade inflammation
  → ↑ MMP-9
       ├── Arteries: thins collagen cap → plaque rupture (MI/stroke)
       └── Brain: disrupts BBB → "leaky brain"
            → Neuroinflammation
            → ↓ Transmitter production + ↑ reuptake
            → Depression / anhedonia (early AD clue)
```

**Callout:** Fix inflammatory tone **before** assuming SSRI non-response is “treatment-resistant depression.”

## 🐟 Infographic 3: "The 2-Gram DHA Rule"

**Title:** Dose for the Brain, Not the Marketing Label

| Parameter | Target |
|---|---|
| Therapeutic DHA dose | **2 g/day** |
| Duration | **Lifelong** (not a 16-week course only) |
| Plasma phospholipid saturation | **~6 weeks** |
| Brain DHA turnover / reconsolidation | **~2.5 years** |
| Brain omega-3 that is DHA | **97%** |
| Eye omega-3 that is DHA | **93%** |
| Average dietary DHA (many patients) | **<100 mg/day** |

**Footer:** Framingham signal cited: highest blood DHA → **~47% lower** dementia/AD risk.

## 🤝 Infographic 6: "Lutein Guards DHA"

**Title:** Partners at the Inner Mitochondrial Membrane

```
DHA (long-chain PUFA)     ← highly oxidation-prone
         ↕ sits beside
LUTEIN (fat-soluble carotenoid)
         → quenches peroxidation
         → protects membrane fluidity
         → less "rancid fat" → less microglial cleanup storm
```

**Hallmark:** Excess lipid peroxidation spans Alzheimer’s, Parkinson’s, ALS, and related neurodegenerative states.

## Infographic 1: "Oil Pulling in 5 Steps"

**Title:** Ayurvedic Oral Detox — Kabbalah / Gandusha

```
1. Choose oil     → Sesame (classic) / Coconut (modern) / Sunflower
2. Measure        → 1 Tbsp (10–15 mL)
3. Swish gently   → 10–20 minutes (build up if beginner)
4. Spit           → Trash can — NOT the sink
5. Finish         → Brush + tongue scrape
```

**Footer:** Adjunct only — not a replacement for dental care. Morning empty stomach or bedtime.

## Infographic 6: "Clinician AI Safety Checklist"

**Title:** Before You Trust the Output

- [ ] I already know the disease well enough to spot nonsense
- [ ] Prompt includes patient “fingerprint” (history, culture, goals)
- [ ] I explicitly asked for integrative / traditional options if desired
- [ ] I verified every citation (or didn’t ask for any)
- [ ] I accept **full liability** — AI is not a co-signer
- [ ] Scribe notes re-read before chart lock; consent documented

**Footer:** Dull knife → injury. Sharpen with knowledge + layered prompts.

## ⚖️ Infographic 3: "Kill vs Restore Decision Tree"

**Title:** Before You Order the Antimicrobial

```
Stool flag (e.g. EPEC, Blasto)
        │
        ├─ Asymptomatic? → Often observe / pass-through (≤~14 days)
        │
        ├─ Symptoms + bigger terrain (mold, constipation, trauma)?
        │         → Treat terrain first; organism may be bystander
        │
        └─ Autoimmunity / low diversity?
                  → ADD competition (ferments, FMT, helminths)
                     not endless whack-a-mole
```

**Pearl:** Diarrhea can be clearance — don’t always suppress it.

## 🪱 Infographic 4: "Helminthic Therapy Snapshot"

**Title:** *Necator americanus* as Immune Peptide Factory

**Footer:** Not a miracle cure — ecosystem tool, study designs imperfect.

## 🥬 Infographic 6: "Ferments Beat Fiber Push"

**Title:** Stanford Teaching Point (~10-Week Ferment Study)

| Strategy | Diversity | Inflammation |
|---|---|---|
| Increase fiber | Modest / variable | Variable |
| Increase fermented foods | ↑↑ | ↓ |

**Prescriptive ladder:**
```
⅛ tsp sauerkraut juice → ¼ tsp → small solid ferment
If fail → yogurt → rotating multi-species probiotic (no mandatory inulin)
```

**Soil rhyme:** regenerative farms use sauerkraut juice ~2 years to clear glyphosate residue.

## 💧 Infographic 7: "Constipation Foundation Stack"

**Title:** Before FMT or Colonics — Ask This

```
1. Water intake          ← most skipped question (even Mayo/Cleveland pathway)
2. Motility supports     ← beets, vitamin C, cautious Mg citrate (~300–400 mg)
3. Sleep                 ← “brain squeeze” / dementia risk if deprived
4. Only then             ← colonics (avoid dependency) / FMT candidacy
```

**Parkinson’s signal:** ~20 years constipation often precedes diagnosis.  
**Lab metaphor:** hard stool → huge fiber pellet, tiny microbial pellet after spin.

## 💊 Infographic 8: "Vitamin C Bowel-Tolerance Ladder"

**Title:** Depletion Gauge + Motility Tool

| Step | Dose idea (as taught) |
|---|---|
| Start | ~6 g/day unbuffered C (or ~4 g ascorbate per panel note) |
| Titrate | +1 g/day |
| Stop / mark | Soft diarrhea **or** ~25 g/day |
| Optional add | High-dose vitamin A (not if pregnant) — FOXP3 / Treg support |

**Mg citrate caveat:** >~600 mg/day without results → change strategy, don’t just flood the lumen.

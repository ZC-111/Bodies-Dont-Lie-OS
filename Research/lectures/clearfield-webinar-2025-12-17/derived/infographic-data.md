## 💊 Infographic 3: "Therapy Ladder When Hormones Aren’t an Option"

**Title:** Gersh Preference Order (Non-Estradiol Path)

| Rank | Option | Notes |
|---|---|---|
| ★★★ | **Estradiol** | Gold standard — always first if appropriate |
| 1 | SSRI / SNRI | Paroxetine FDA-approved for VMS; class effect |
| 2 | Gabapentin | Off-label; supportive data |
| 3 | Avoid clonidine | Largely shunned |
| Last | Fezolinetant (Veozah) | ~**$600/mo**; liver-injury warning; weeks to effect |
| Emerging | Elinzanetant | Dual NK1/NK3 — same class caveats |

**Footer:** Blocking NK receptors hits liver too — you can’t “aim” only at the hypothalamus.

## 👩‍⚕️ Infographic 5: "Gersh Estradiol Starting Map"

**Title:** Dose for Optimization — Not Just Flash Suppression

```
Recently menopausal (<5 years)
  │
  ├─ Patch 0.1 mg  ──► often ~100 pg/mL
  │     └─ too tender? → 0.05 then titrate up
  │
  ├─ Place patch on UPPER BUTTOCK (better absorb than abdomen)
  │
  ├─ Gel / compounded cream OK; spray usually too weak
  │
  └─ Goal: comfort + bone/brain/metabolic support
           (not “lowest dose that barely stops flashes”)
```

**Pair with:** Vaginal progesterone **200 mg** typical start (range 200–400 mg).

## 🩸 Infographic 6: "Progesterone Delivery Reality Check"

**Title:** Route Matters More Than Brand Hype

| Route | Verdict |
|---|---|
| **Vaginal micronized** | Preferred — skips first-pass |
| Oral micronized | 80–90% → metabolites; less parent P4 |
| Topical cream | Unreliable systemic delivery (21-carbon molecule) |
| Rectal | Fallback if vaginal refused |
| Post-hysterectomy topical | Acceptable “monitor & cheat” per Gersh |
| Wiley-style mega-dosing | Concept OK; levels can hit ~800 pg/mL E2 — not physiologic |


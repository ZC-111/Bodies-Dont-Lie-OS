# Immune Research

## Purpose

Hold source material and inquiry for immune function — including autoimmunity, mold/mycotoxins, inflammation, rheumatology, immuno-oncology, and related CME.

## What Belongs Here

- Conference decks / notes tagged immune or autoimmune
- **Mold, mycotoxins, CIRS / biotoxin illness** — PDFs, lectures, protocols
- Papers on autoimmunity, cytokines, immune protocols
- Open questions linking immune findings to clinical practice

## Branch Rules

- **Autoimmune is a topic under immune**, not a separate branch
- **Mold / mycotoxins go under immune**, not a separate `mold/` branch
- Vitamins used for immune support still catalog under [nutrition/](../nutrition/README.md) with an immune cross-link
- Herbals for immune/mold protocols → [materia-medica/](../materia-medica/README.md) (or immune if the lecture focus is disease, not the plant)
- Link out to [nutrition/](../nutrition/README.md) when diet/fasting modulates immune outcomes
- Link to [acupuncture/](../acupuncture/README.md) only for explicitly related lectures (e.g. immune-point strategies)

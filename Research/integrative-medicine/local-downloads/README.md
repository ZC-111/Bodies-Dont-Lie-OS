# Local Downloads — Lecture Catalog

## Purpose

Index medical lecture packs already on this Mac (`/Users/nuu/Downloads`) before selective import into Living Tree branches.

## Catalog

- Data: [`data/local-downloads-catalog.json`](data/local-downloads-catalog.json)
- Rebuild: `python3 scripts/build_local_downloads_catalog.py`

## Rules

- Catalog first; do not mass-move binaries
- Primary branch + `medical_terms[]` / `themes[]` per pack
- Screenshots counted, not listed file-by-file
- Practice/business packs (e.g. DPC) stay low priority

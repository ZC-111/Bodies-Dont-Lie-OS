# Integrative Medicine Research

## Purpose

Hold multi-domain conference archives and integrative CME that span more than one Living Tree branch (immune, nutrition, osteopathic, longevity, acupuncture-adjacent).

## What Belongs Here

- Conference folders (e.g. AOSRD) with catalogs and optional source copies
- Cross-branch indexes — theme tags point to real branches; do not duplicate leaves here

## Branch Rules

1. Prefer domain branches (`immune/`, `nutrition/`, `acupuncture/`) for single-topic material
2. Use this folder when the **source event** is multi-topic
3. Tag each lecture with target branches; link, don't copy

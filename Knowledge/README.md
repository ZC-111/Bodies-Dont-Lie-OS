# Knowledge

## Purpose

Store atomic knowledge objects — each file answers exactly one question about a domain.

## What Belongs Here

- Single-concept explanations (e.g. "What is inflammation?")
- Subfolders by domain as branches emerge (see [BDL-002 Living Tree](../Constitution/BDL-002-Living-Tree.md))
- Definitions that don't belong in the Constitution
- Linked modules that compose into larger understanding

## Naming Rules

- Use question form: `What-Is-Inflammation.md` or domain prefix: `immune/What-Is-Inflammation.md`
- One complete idea per file
- Link to related knowledge objects; never duplicate content

## Related Folders

- [Research](../Research/README.md) — Source evidence for knowledge claims
- [Constitution](../Constitution/README.md) — Principles that govern how knowledge is written
- [Archive](../Archive/README.md) — Retired or superseded knowledge

# Projects

## Purpose

Track active work that applies the [Wayfinding Cycle](../Constitution/BDL-001-Wayfinding-Kernel.md) to real problems.

## What Belongs Here

- Active project folders (BDL-500 series)
- Project-specific decisions and outcomes
- Links to knowledge and skills used

## Naming Rules

- `BDL-5XX-Project-Name/` for numbered projects
- Each project gets its own folder with a README and eight stage files (`01-Observe.md` … `08-Learn.md`)
- See [BDL-500-Seed-Living-Tree](BDL-500-Seed-Living-Tree/README.md) as the reference project

## Related Folders

- [Research](../Research/README.md) — Evidence gathered during projects
- [Reflection](../Reflection/README.md) — What changed during project work
- [Archive](../Archive/README.md) — Completed projects
